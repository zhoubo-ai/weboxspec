## Recipe declarations

Names, descriptions, base prices, base allergens, cuisines, protein, spice and customization choices are transcribed from original PRD §6 (not Appendix A). Original PRD data remains unchanged. Option-level allergens are explicitly authored demo recipe declarations because the PRD has no option-level labels: all three wheat pastas and both wheat buns contain Gluten; Cheese contains Dairy; Mayo and Fried Egg contain Egg; Mixed Grains is defined here as brown rice, quinoa and barley, containing Gluten. Other options have no additional declared labels in this demo recipe. These are sample recipe declarations, not inferences from a dish name or image and not a claim of allergen safety. Administrators must maintain declarations for actual recipes.
